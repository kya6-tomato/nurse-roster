# 夜勤待機シフト管理アプリ

看護師の夜勤待機（オンコール）シフトを、4週間（木曜始まり〜水曜終わり）単位で
条件を守りながら自動生成し、サイト上で細かい手直しもできるようにするツールです。

## 最初の準備（1回だけ）

1. このフォルダの中にある **`setup.bat`** をダブルクリックします。
   - 黒い画面が出て、いろいろ文字が流れます。「インストールが完了しました」と出たら、何かキーを押して閉じてください。
   - ここで一度だけ、少し時間がかかります（数分程度）。
   - **Pythonが入っていないパソコンでも大丈夫です。** `setup.bat` が自動でPythonを探し、見つからなければ
     インターネットからダウンロードして、このパソコン（今ログインしているユーザー）用にインストールします。
     管理者権限は不要ですが、インターネット接続が必要です。
   - もし自動インストールがうまくいかない場合は、黒い画面に手動インストールの手順が表示されるので、その通りに進めてください
     （https://www.python.org/downloads/ からダウンロードし、**「Add python.exe to PATH」に必ずチェックを入れて**
     インストールしてから、もう一度 `setup.bat` を実行してください）。

## 毎回の使い方

1. このフォルダの中の **`run_server.bat`** をダブルクリックします。
2. 少し待つと、自動でブラウザが開きます（開かない場合は `http://localhost:5000` にアクセスしてください）。
3. 使い終わったら、黒い画面を閉じれば終了します。

## 使い方のおおまかな流れ

1. 「看護師管理」ページで、看護師の名前・役職を登録します。
2. 同じページの「組み合わせ設定」で、勤務させてよい2人組にチェックを入れて保存します
   （自動生成は、ここで登録した組み合わせしか使いません。ある程度の組み合わせを登録しておく必要があります）。
3. 「期間一覧」ページで、「新しい期間を作成」（開始日は必ず木曜日）。
4. 期間のページを開き、「休み希望」があれば、一覧表の該当マスで「希望」または「固定」を選んで「この内容で保存する」を押します。
   「固定」に設定した日は、自動生成でどんな時も動かされません。
5. 「自動生成する」を押すと、条件を守った形でシフトが自動で組まれます。
6. 気になるところがあれば、マスの「編集」から手直しできます。手直しした結果、条件から外れた場合は下の「条件チェック結果」に赤字・オレンジ字で表示されます。
7. できあがったら「エクセルへ出力」で、印刷・配布用のエクセルファイルをダウンロードできます。
8. 作り直したい・不要になった期間は、「削除」から消せます（元に戻せないので確認ダイアログが出ます）。

## データの保存場所・バックアップ

- 看護師の情報やシフトのデータは、このアプリのフォルダの**外**、
  「ドキュメント」フォルダの中の `夜勤待機シフト管理アプリ` フォルダに保存されます
  （`ドキュメント\夜勤待機シフト管理アプリ\data`）。
- こうすることで、アプリ本体（このフォルダ）を新しいバージョンに入れ替えても、登録した看護師やシフトのデータは消えずに引き継がれます。
- バックアップしたいときは、この `夜勤待機シフト管理アプリ` フォルダをそのままコピーしてUSBメモリなどに保存してください。
- 以前のバージョンをお使いだった場合、初回起動時にアプリのフォルダの中にあった古いデータを自動でこちらに引き継ぎます
  （古いデータはそのまま残るので、削除して問題ありません）。

## 今できること

看護師の登録（氏名・役職）、勤務させてよい組み合わせの登録、期間の作成・削除、
休み希望の登録（一覧表での「希望」「固定」の入力）、条件を守ったシフトの自動生成、
サイト上での手直し、条件チェック、エクセルへの出力。

## もし動かないとき

- `setup.bat` や `run_server.bat` を実行して出てくる黒い画面に、エラーの内容が表示されます。その内容を教えてください。
- 「Pythonが見つかりません」と出る場合は、先に `setup.bat` を実行してください（自動でインストールされます）。
- 自動インストールが失敗する場合は、インターネット接続を確認するか、黒い画面に表示される手順で手動インストールしてください。
- 手動でPythonをインストールする場合は、「Add python.exe to PATH」のチェックを忘れずに入れてください。
